# slova-first-videos

Відео для першого входу в застосунок Slova після intro: по кілька на мову, яку вчить користувач.
Застосунок читає файл напряму з цього репозиторія:

```
https://raw.githubusercontent.com/sashasobchuk/slova-first-videos/main/first-videos.json
```

Якщо файл недоступний, застосунок бере вбудований запасний список.

## Формат

```jsonc
{
  "version": 1,            // ціле число; піднімайте при кожній зміні
  "videos": {
    "en": [{ "id": "ibjUpk9Iagk", "title": "TED-Ed — The history of chocolate" }],
    "zh-Hans": [{ "id": "rbLlUXT72C4" }],
    "hi": []               // порожній масив — відео ще нема, екран відкриється як зазвичай
  }
}
```

- Ключ — код мови (BCP 47, напр. `zh-Hans`). Застосунок пробує повний код, потім базовий (`en-US` → `en`).
- `id` — ID відео YouTube. `title` необов'язковий, лише для людини.

## Промпт для LLM (пошук відео)

Замість `<ОБ'ЄКТ>` встав вміст `first-videos.json`:

```
Нижче JSON: ключ — код мови (BCP 47), значення — масив відео YouTube для першого запуску
мовного застосунку. Порожній масив означає, що відео для цієї мови ще нема. Знайди по 3 відео
для КОЖНОЇ мови з порожнім масивом. Вимоги до відео:
- люди говорять саме цією мовою (не дубляж чи англійська з автосубтитрами);
- є субтитри цією мовою (ручні або автоматичні);
- тривалість 3–15 хвилин, чітке мовлення, не музика і не стрім;
- за можливості без реклами: некомерційні, освітні, державні, університетські канали чи Creative Commons; не вигадуй гарантій щодо реклами;
- не політичні, не клікбейтні, без 18+, доступні в усьому світі;
- перевірені: GET https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=<ID>&format=json має повернути 200.
Не вигадуй ID: бери лише ті, що реально побачив у пошуку або на сторінці відео. Якщо для мови не
знайшов перевірених відео, залиш масив порожнім і так і напиши.
Поверни лише готові елементи масиву: { "id": "...", "title": "Канал — Назва відео" }.

<ОБ'ЄКТ>
```
